Project Overview

Can we predict human connection using data?

The Target Output

  • Positive (1): Mutual Match, Date Happened, Relationship Formed
  • Negative (0): Ghosted, Blocked, Ignored, Catfished

The Dataset Context

  • 50,000 synthetic records
  • Demographics + Behavior interactions

Exploratory Data Analysis

  • Target Balance: 10 match_outcome classes are perfectly balanced (~5,000 each).
  • Distributions: Uniformly distributed across synthetic variables.
  • Correlations: No strong linear correlation between numeric variables detected.
  • Outliers: Boxplots show no extreme anomalies; all ranges plausible.

Preprocessing Pipeline

  • Binary Target: 10 classes → Positive vs Negative.
  • Ordinal Encoding: Income and Education collapsed into Low, Middle, High tiers.
  • One-Hot Encoding: 7 nominal columns → 43 binary columns.
  • Multi-Hot Encoding: 49 unique `interest_tags`.
  • Standardization: Applied `StandardScaler`.
Final Shape: 113 Feature Columns

Dimensionality & Selection

Feature Selection (Top 67)

  • ANOVA F-Score: Captures linear class separation.
  • Mutual Information: Non-linear dependencies.
  • Strategy: Union of top 40 from both methods.

PCA (Top 55)

  • Retained 95.2% of total variance.

Base Model Evaluation

Trained on an 80/20 stratified split. 6 base models evaluated:

Logistic Reg Decision Tree Random Forest XGBoost KNN Bagging SVM
  • GPU Acceleration: Auto CUDA detection block.
  • Parallel Optimization: Prevented thread collision via cross-validation management.

Hyperparameter Tuning

  • Method: RandomizedSearchCV across the Top 3 Models.
  • Scale: 30 iterations × 5-fold CV = 150 fits per model.
  • Target Metric: F1-Score (balances precision and recall).

Academic Rigor & Ethics

  • Class Imbalance Mitigation: class_weight='balanced'
  • Statistical Significance: Paired t-tests proved the performance gaps are real (p = 0.0004).
  • Algorithmic Fairness: Evaluated Demographic Parity across gender identities.
  • Explainability (Right): Top Features identified via Tree model.

Final Verdict

The models achieved a consistent ROC-AUC of ~0.50.

This scientifically proves that the features in this synthetic dataset do not contain hidden predictive signals for a "Meaningful Connection".

However, the highly optimized, parallelized, and rigorous ML pipeline we built is perfectly primed for deployment on real-world data.
