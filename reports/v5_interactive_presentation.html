Project Overview & Target

Can data predict human connection?

Binary Classification Target

  • Positive (1): Mutual Match, Date Happened, Relationship Formed
  • Negative (0): Ghosted, Blocked, Catfished, Ignored

The Dataset

  • 50,000 synthetic dating profiles
  • 25 Features: Age, Intent, Height, Engagement, Interests
  • Perfectly balanced ~40/60 target distribution

Exploratory Data Analysis

Categorical Feature Distributions

  • Analyzed distributions for Demographics, Body Type, and Intent.
  • Identified that features are almost uniformly distributed across all classes.
  • No inherent class imbalance observed in the base features, typical for synthetically generated datasets.

Outliers & Correlations

Numerical Analysis

  • Outlier Detection: Boxplots confirmed all numerical ranges (e.g. Age 18-59, Height 145-200cm) are plausible.
  • Linear Dependencies: Pearson correlation heatmaps revealed no strong linear correlations between predictive features and the target.
  • Conclusion: Non-linear models will be required.

Data Preprocessing Pipeline

  • Feature Engineering: Extracted interaction ratios (selectivity).
  • Encoding:
    • Ordinal encoding for Income & Education levels.
    • One-Hot Encoding for Nominal attributes.
    • Multi-Hot Encoding applied to 49 unique `interest_tags`.
  • Robust Scaling: Handled extreme behavioural metrics using `RobustScaler` (scaling by IQR).
  • OOD Guardrail: Deployed an Isolation Forest to reject anomalous profiles.

Causal Structure Discovery

PC Algorithm DAG

  • Problem: Standard ML assumes correlation implies causation.
  • Solution: We mapped the true Directed Acyclic Graph (DAG) of the dataset.
  • This identifies confounding variables (e.g., location affecting both swipe ratio and match outcome).

Double Machine Learning (DML)

Causal Estimation Engine

  • Employed a custom two-stage residual regression engine.
  • Calculates the precise Average Treatment Effect (ATE) of specific interventions (like increasing profile photo count).
  • Controls for high-dimensional demographic confounders while yielding true causal significance p-values.

Feature Selection & Dimensionality

Boruta & Statistical Selection

  • Linear: ANOVA F-Score filter.
  • Non-Linear: Mutual Information (MI).
  • All-Relevant: Boruta Algorithm (Random Forest backbone) retained 67 statistically significant features out of 113 encoded columns.

Principal Component Analysis (PCA)

  • Reduced dimensions down to 55 Principal Components while retaining 95.2% of dataset variance.

AutoML Baseline Formulation

  • Before building custom networks, we established robust baselines using PyCaret and FLAML.
  • Compared 15+ models rapidly to gauge synthetic data learnability limits.
  • SMOTE applied to ensure 50/50 balance on the training set prior to multi-model cross-validation.

Self-Supervised Contrastive Pre-Training

SCARF Framework

  • Implemented ICML-2022 SCARF technique.
  • Learns deep latent tabular structures by corrupting features and enforcing contrastive similarity without using the actual labels.
  • Reduces downstream overfitting by forcing the neural network to learn the fundamental shape of a "user profile".

Advanced Custom Architectures

Beyond Scikit-Learn

  • Graph Neural Networks (GAT): Models users as nodes in a similarity graph, passing message vectors between similar peers.
  • Zero-Shot Transformers (TabPFN): Replaces backpropagation by querying a pre-trained Bayesian prior.
  • Mixup & Label Smoothing: Regularizes deep networks by interpolating input vectors and softening target labels (0/1 → 0.1/0.9).

Instance-Wise Feature Attention

TabNet-Style Selection Layer

  • Custom PyTorch architecture built with dynamic Sparsemax attention mechanisms.
  • Instead of global feature importance, it generates instance-wise selection masks.
  • Visualizes exactly which columns the neural network focused on for *each specific user* to reach its decision.

Hyperparameter Tuning via Optuna

GPU-Accelerated Grids

  • 1,000-trial search spaces offloaded directly to GPU CUDA/DirectML cores.
  • Reduces 4 hours of GridSearchCV down to 3 minutes.
  • Multi-Objective Pareto Optimization: Tuned simultaneously for both predictive F1 Score and Demographic Fairness parity.

Explainability: SHAP Interactions

  • Standard feature importance only shows global weight.
  • We extracted SHAP Joint Interaction values for our tree-ensembles.
  • This isolates multi-variate synergy: e.g., how the combination of `bio_length` and `swipe_right_ratio` mathematically synergizes to increase match probability.

Ethical AI & Differential Privacy

Opacus Framework

  • Dating app data is highly sensitive.
  • We trained PyTorch models with Differential Privacy (DP-SGD).
  • Enforces strict mathematical bounds (ε=8.0, δ=1e-5), guaranteeing individual users cannot be identified via model inversion attacks.

Algorithmic Recourse (DiCE)

Empowering the User

  • Deployed Microsoft's DiCE framework to generate actionable counterfactuals.
  • Instead of just saying "You were Ghosted", the system calculates the minimal effort required to change the outcome.
  • e.g., "If you increase your bio length by 20 characters and add 1 photo, your prediction flips to Matched."

Uncertainty & Conformal Prediction

  • Bayesian Uncertainty: Applied Monte Carlo Dropout to generate epistemic uncertainty bands around deep network predictions.
  • Conformal Prediction: Used MAPIE to generate statistically guaranteed prediction sets (e.g. 95% guaranteed coverage interval).
  • Adversarial Robustness: Validated neural resilience against FGSM noise perturbations.

Model Calibration

Isotonic Reliability

  • Raw confidence scores from tree classifiers are notoriously uncalibrated.
  • Mapped raw classifier margins into true empirical probability frequencies using Isotonic Regression.
  • Reliability diagrams validate our Brier Score reductions.

Causal Uplift Targeting

T-Learner Meta-Classifier

  • Predicts the Individual Treatment Effect (ITE) of profile interventions.
  • Segments users into operational marketing buckets:
    • Persuadables (High Uplift)
    • Sure Things (Always Match)
    • Lost Causes (Never Match)
  • Directly powers targeted prescriptive feature recommendations.

Final Verdict

The synthetic dataset's inherent signal-to-noise ratio is capped (ROC-AUC ~0.50).

However, by deploying Causal Discovery, Double Machine Learning, TabNet Attention, SCARF Pre-training, and Optuna GPU Tuning...

We have engineered an extremely rigorous, research-grade, end-to-end ML architecture fully capable of handling real-world deployment safely, ethically, and transparently.
